================================================================
  PANDUAN BUILD APK & HOSTING DATA - SEARCH ROLEPLAY MOBILE
  Package ID : com.searchroleplay.mobile
  Target Repo: https://github.com/Reyhanzz/search-roleplay-mobile
================================================================

1. CARA BUILD FILE .APK OTOMATIS GRATIS DI GITHUB ACTIONS
----------------------------------------------------------------
Kamu TIDAK perlu install Android Studio di PC. Cukup pakai GitHub:

1) Buka https://github.com/new
   - Repository name : search-roleplay-mobile
   - Visibility      : Public (supaya auto-updater & remote config terbaca tanpa login)
   - Klik "Create repository" (jangan centang README/gitignore).

2) Buka PowerShell / CMD di folder:
   D:\Project\anti afk gta samp\Search_Roleplay_Mobile

   Jalankan perintah berikut:
   git init
   git branch -M main
   git add .
   git commit -m "Initial Search Roleplay Mobile v1.0.0"
   git remote add origin https://github.com/Reyhanzz/search-roleplay-mobile.git
   git push -u origin main

3) Buka tab "Actions" di GitHub repo kamu:
   - Workflow "Build & Release Search Roleplay Mobile APK" otomatis jalan (~4-6 menit).
   - Setelah centang hijau, klik run tersebut -> scroll ke bawah ke bagian "Artifacts"
     -> klik "SearchRoleplayMobile-APK" untuk mengunduh SearchRoleplayMobile.apk!

4) Untuk langsung mempublikasikan ke GitHub Releases (v1.0.0):
   git tag v1.0.0
   git push origin v1.0.0
   GitHub Actions otomatis membuat Release v1.0.0 berisi SearchRoleplayMobile.apk
   dan manifest_mobile.json (lengkap dengan SHA-256 otomatis).


2. CARA PASANG LINK DATA CACHE GTA ANDROID (LITE / FULL .ZIP)
----------------------------------------------------------------
Supaya tombol "DOWNLOAD GAME DATA" di HP pemain langsung jalan otomatis:

1) Siapkan file .zip data GTA SA Android 2.10 kamu (berisi folder texdb/, audio/, data/, SAMP/).
   Catatan: Launcher sudah punya smart extractor, jadi baik di dalam .zip berstruktur
   "files/texdb/...", "com.rockstargames.gtasa/files/texdb/...", atau langsung "texdb/...",
   semuanya otomatis diekstrak rapi ke Android/data/com.searchroleplay.mobile/files/.

2) Upload file .zip tersebut ke Google Drive / Dropbox / MediaFire / Direct Hosting.
   (Untuk Google Drive, pastikan sharing link = "Anyone with the link").

3) Edit file "manifest_mobile.json" di branch main GitHub kamu:
   Isi bagian "android_data_url":
   "android_data_url": "https://drive.google.com/file/d/ID_FILE_KAMU/view?usp=sharing"

4) Klik Commit changes -> semua pemain yang membuka APK langsung bisa tekan
   "DOWNLOAD GAME DATA" tanpa perlu update ulang APK!


3. CARA TES MANUAL DATA LOKAL DI HP (TANPA DOWNLOAD ULANG)
----------------------------------------------------------------
Kalau kamu sudah punya folder data GTA SA Android 2.10 di HP, kamu juga bisa:
- Install SearchRoleplayMobile.apk -> buka sekali (supaya foldernya terbentuk)
- Atau masukkan link zip sementara di tab Settings -> Custom Data Pack URL -> Download Data.
- Folder penyimpanan game ada di:
  Internal Storage/Android/data/com.searchroleplay.mobile/files/
